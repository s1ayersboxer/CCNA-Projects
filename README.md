# CCNA Labs — Cisco Packet Tracer

A collection of hands-on networking labs built in Cisco Packet Tracer, following the **Jeremy's IT Lab CCNA course**. Each lab covers a specific set of topics and includes a full topology, addressing plan, CLI configurations, and verification results.

---

## Labs

| # | Lab | Topics | Status |
|---|-----|--------|--------|
| 01 | [Basic Network Design](https://github.com/s1ayersboxer/CCNA-Projects/tree/main/Network%20Design) | Subnetting, VLANs, Trunking, DTP, VTP, Router-on-a-Stick | ✅ Complete |
| 02 | [Enterprise Network Lab](https://github.com/s1ayersboxer/CCNA-Projects/tree/main/Enterprise%20Network%20Lab) | VLANs, 802.1Q Trunking, Inter-VLAN Routing, STP, Port Security, DHCP, DNS, RIP, OSPF, EIGRP | ✅ Complete |

## Skills Demonstrated

| Skill | Tools / Protocols |

| Dynamic Routing | RIP v2, OSPF, EIGRP |
