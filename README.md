# CCNA Labs — Cisco Packet Tracer

A collection of hands-on networking labs built in Cisco Packet Tracer, following the **Jeremy's IT Lab CCNA course**. Each lab covers a specific set of topics and includes a full topology, addressing plan, CLI configurations, and verification results.

## Labs

| # | Lab | Topics | Status |
|---|-----|--------|--------|

| 02 | [Enterprise Network Lab](https://github.com/s1ayersboxer/CCNA-Projects/blob/main/Network%20Design/02/02%20-%20Enterprise%20Network.md) | VLANs, 802.1Q Trunking, Inter-VLAN Routing, STP, Port Security, DHCP, DNS, RIP, OSPF, EIGRP | ✅ Complete |

## Skills Demonstrated

| Network Services | DHCP, DNS |
| Dynamic Routing | RIP v2, OSPF, EIGRP |
